# Deployment Guide

This guide covers deploying the Kalshi-Polymarket arbitrage bot to an AWS EC2 instance.

## AWS EC2 Setup

For optimal latency to exchange matching engines, deploy the bot in the **us-east-1** region.
- **Instance Type:** `t3.micro` or `t3.small` is sufficient for the bot's computational requirements.
- **OS:** Ubuntu Server 22.04 or 24.04 LTS.

### Security Group Configuration
- **Inbound SSH:** Allow port 22 from your IP address.
- **Inbound Dashboard:** (Optional) Expose the dashboard port (e.g., 8000) if not using an SSH tunnel. Using an SSH tunnel is strongly recommended for security.

## Automated Provisioning

Once your EC2 instance is running, you can use the provided setup script to automate dependencies and configuration.

1. SSH into the instance:
   ```bash
   ssh -i your-key.pem ubuntu@your-ec2-ip
   ```
2. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Kalshi_ARB.git
   cd Kalshi_ARB
   ```
3. Run the setup script:
   ```bash
   sudo ./deploy/setup_ec2.sh
   ```
   *The script will install Python, necessary system packages, setup the virtual environment, and configure systemd.*

## Systemd Service Configuration

The bot is designed to run continuously in the background managed by `systemd`.

- **Start the bot:**
  ```bash
  sudo systemctl start kalshi-arb
  ```
- **Stop the bot:**
  ```bash
  sudo systemctl stop kalshi-arb
  ```
- **Enable on boot:**
  ```bash
  sudo systemctl enable kalshi-arb
  ```

## Accessing the Dashboard via SSH Tunnel

To view the real-time FastAPI dashboard from your Windows machine securely without exposing ports to the public internet:

Run the following command from your local Windows terminal (Powershell or Command Prompt):
```powershell
ssh -i C:\path\to\your-key.pem -L 8000:localhost:8000 ubuntu@your-ec2-ip
```

Then, open your web browser and navigate to `http://localhost:8000`. You will be prompted for the HTTP Basic Auth credentials configured in your `.env` file.

## Monitoring and Logs

The systemd service logs stdout and stderr to `journald`.

- **View live logs:**
  ```bash
  sudo journalctl -u kalshi-arb -f
  ```
- **View recent logs:**
  ```bash
  sudo journalctl -u kalshi-arb -n 100
  ```

Additionally, application-level logs generated by the bot will be located in the `logs/` directory.

## Updating the Bot

To update the bot with the latest code changes:

1. Navigate to the repository:
   ```bash
   cd ~/Kalshi_ARB
   ```
2. Pull the latest changes:
   ```bash
   git pull origin main
   ```
3. Restart the service to apply changes:
   ```bash
   sudo systemctl restart kalshi-arb
   ```
